# Shopping Website

## Overview
This project is a simple frontend shopping website built using HTML, CSS, and JavaScript. It serves as a demonstration of how to create a basic e-commerce platform with product listings, a shopping cart, and a checkout process.

## Project Structure
```
shopping-website
├── src
│   ├── index.html
│   ├── styles
│   │   └── style.css
│   ├── scripts
│   │   ├── main.js
│   │   ├── products.js
│   │   └── cart.js
│   └── pages
│       ├── home.html
│       ├── products.html
│       └── checkout.html
├── assets
│   └── data
│       └── products.json
└── README.md
```

## Features
- **Homepage**: A welcoming page with promotional content and navigation links.
- **Product Listings**: A dedicated page that displays all available products fetched from a JSON file.
- **Shopping Cart**: Users can add or remove items from their cart and view their total.
- **Checkout Page**: A simple interface for users to review their cart and proceed with the purchase.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `src/index.html` file in a web browser to view the website.
3. Ensure that all assets are correctly linked and that the JavaScript files are functioning as intended.

## Usage
- Navigate through the homepage to view promotions.
- Click on the "Products" link to view available items.
- Add items to your cart and proceed to the checkout page to complete your purchase.
